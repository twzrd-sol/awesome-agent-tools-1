# Contribution Guidelines

Thank you for your interest in contributing to **Awesome Agent Tools**!

## Adding a New Entry

Please ensure your pull request adheres to the following guidelines:

- **One item per pull request.** This makes it easier to review and discuss.
- Search previous suggestions before making a new one to avoid duplicates.
- Use the following format: `[Name](link) - Description.`
  - The description should be concise, clear, and informative.
  - Start the description with a capital letter and end with a period.
  - Do not use promotional language (e.g., "the best", "the most popular").
- Add the item to the **bottom** of the relevant category.
- Check your spelling and grammar.
- Make sure your text editor is set to remove trailing whitespace.
- The link should point to the GitHub repository, official website, or primary documentation.

## Criteria for Inclusion

To be included, a tool or resource should:

- Be directly related to building, deploying, or managing AI agents.
- Be actively maintained (commits in the last 6 months for open-source projects).
- Have sufficient documentation for users to get started.
- For open-source projects: have at least **50 GitHub stars** (to ensure community validation).
- Not be a duplicate of an existing entry.

## Creating a Pull Request

1. Fork this repository.
2. Create a new branch: `git checkout -b add-tool-name`.
3. Make your changes to `README.md`.
4. Commit your changes: `git commit -m "Add Tool Name"`.
5. Push to your fork: `git push origin add-tool-name`.
6. Open a pull request with a clear title and description.

## Suggesting a New Category

If you think a new category is needed, please open an issue first to discuss it. Include:

- The proposed category name.
- A brief description of what it would include.
- At least 3 tools/resources that would fit in this category.

## Reporting Issues

If you find a broken link, outdated entry, or any other issue, please open an issue and include:

- The name of the tool/resource.
- What the issue is (broken link, project archived, etc.).
- A suggested fix, if applicable.

## Code of Conduct

By participating in this project, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping make this resource awesome!
